# AI Learning Roadmap Generator

A Streamlit web application that generates personalized AI learning roadmaps using the **Google GenAI SDK** and **Gemini Flash** models.

## Features
- Customize target AI topic, experience level, study duration, and weekly hours.
- Optional field for existing background skills or tools.
- Generates a structured, phase-by-phase roadmap with hands-on project ideas.
- Export the generated roadmap as a Markdown (`.md`) file.
